🚀 Personal Portfolio Website

👨‍💻 About the Project

This is my personal developer portfolio website built using HTML, CSS, and JavaScript. It showcases my skills, projects, GitHub repositories, resume, and contact information in a clean and responsive design. The goal of this project is to present my work in a professional way for internships and job opportunities.

✨ Features

🎨 Modern and responsive UI design
📱 Mobile-friendly layout
⚡ Smooth animations (AOS effects)
📂 Dynamic GitHub projects integration
🧠 Skills showcase section
📄 Resume download/view option
📬 Contact information section
🌐 Clean and structured navigation

🛠️ Technologies Used

HTML5
CSS3
JavaScript (Vanilla JS)
GitHub API (for fetching projects)
AOS Library (animations)
